## Q007061

- 题型：简答
- 难度：中等

**题目**

```text
MidScene.js的yaml配置文件结构包含哪两个主要部分？各自的作用是什么？
```

**答案**

```text
MidScene.js的yaml配置文件主要包含全局配置和测试用例配置两个部分，分别用于设置测试项目的基本参数和定义具体的测试场景。
```

**解析**

```text
【核心考点】 模型配置 设备配置 测试步骤 断言条件
【题目解析】
yaml 主要分为两部分：全局配置负责模型、设备、环境等通用参数；用例配置负责具体测试步骤和断言。这样可以把环境设置与业务场景分离，便于复用和维护。
【易错提示】
不要把所有参数都堆在用例里，导致每个用例重复配置模型和设备信息，维护成本反而升高。
```

## Q007062

- 题型：简答
- 难度：中等

**题目**

```text
MidScene.js的核心技术特点是什么？与传统自动化测试工具相比有什么优势？
```

**答案**

```text
MidScene.js的核心技术特点是基于大语言模型和计算机视觉，支持自然语言描述测试步骤，与传统自动化测试工具相比有使用门槛低、维护成本低、测试效率高等优势。
```

**解析**

```text
【核心考点】 LLM+CV 自然语言脚本 低代码 自愈能力
【题目解析】
技术特点：结合大语言模型和计算机视觉，支持自然语言描述测试动作。优势是上手快、脚本维护少、改版适应性强；适合探索式 UI 测试和快速回归。回答时可与 Selenium/Appium 的编码成本和维护成本做对比。
【易错提示】
避免只说优点不说限制。对复杂业务校验、验证码、强确定性断言，传统工具或人工仍可能更稳。
```

## Q007066

- 题型：简答
- 难度：中等

**题目**

```text
在运行MidScene.js测试脚本遇到哪些常见错误？如何解决？
```

**答案**

```text
在运行MidScene.js测试脚本时，常见的错误包括元素定位失败、API调用失败和数据格式错误，需要根据具体情况进行解决。
```

**解析**

```text
【核心考点】 元素定位失败 API调用失败 数据格式错误 日志分析
【题目解析】
常见错误三类：定位失败——页面变更，优先用 AI 重新识别；API 失败——检查网络、密钥、模型服务状态；数据格式错误——检查输入字段、JSON/YAML 格式。排查顺序建议：日志 → 配置 → 数据 → 页面。
【易错提示】
遇到失败不要只会重跑脚本。MidScene.js 很多问题都能从模型返回和运行日志中定位根因。
```
