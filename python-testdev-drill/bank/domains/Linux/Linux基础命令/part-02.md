```text
Linux里面sudo的命令知道吗？
```

**答案**

```text
参考：
1、sudo是linux系统管理指令，是允许普通用户只需一些或者全部root命令的一个工具，可以减少root用户的登录和管理时间，提高安全性。
2、sudo不是shell的替代，它是面向每个命令的。
```

**解析**

```text
【核心考点】 Linux基础命令 权限管理
【参考答案要点】
1. 基本概念：sudo（superuser do）是Linux系统管理指令，允许普通用户以root或其他用户身份执行命令，从而减少root登录次数，提升系统安全性。
2. 工作原理：通过/etc/sudoers文件配置用户权限，执行时需输入当前用户密码（可配置免密）。
3. 与su的区别：sudo是面向每个命令的授权，而su是切换用户身份；sudo更安全、更灵活。

回答时建议结合实际使用场景，例如“在CI/CD流水线中，使用sudo执行需要root权限的部署命令”，能体现对安全性和效率的理解。

了解visudo命令（安全编辑sudoers文件）以及sudo -l（查看当前用户可执行的sudo命令），有助于应对深入提问。
```

## Q004476

```text
Liunx文件权限一共10位长度，分成四段，第三段表示的内容含义是什么？
```

```text

```

```text
【核心考点】 Linux文件权限 权限位解析
【题目解析】
Linux文件权限字符串共10位，格式为：-rwxr-xr--。第一段（第1位）表示文件类型；第二段（第2-4位）表示所有者权限；第三段（第5-7位）表示所属组权限；第四段（第8-10位）表示其他用户权限。因此第三段表示文件所属用户组的权限。

【易错提示】
常见混淆：将第三段误认为其他用户权限。记住顺序：所有者→所属组→其他用户。
```

## Q004480

- 题型：简答
- 难度：简单

**题目**

```text
UNIX 中init是什么?
```

**答案**

```text
在基于Unix的计算机操作系统中，init 是系统启动的第一个进程。
Init 是一个守护进程，它会继续运行直到系统关闭。
它是所有其他进程的直接或间接祖先，并自动采用所有孤立进程。
Init在引导过程中由内核启动，如果内核无法启动它，就会发生内核恐慌。
Init 通常被分配进程标识符1。
直到最近，大多数Linux 发行版都使用与 System V 有点兼容的传统 init
而Slackware等一些发行版使用 BSD 风格的启动脚本
而Gentoo等其他发行版则有自己的定制版本。
已经创建了几个额外的 init 实现，试图解决传统版本中的设计限制。
其中包括launchd、服务管理工具、systemd、Runit和OpenRC。
```

**解析**

```text
【核心考点】 操作系统 Init进程 UNIX/Linux
【参考答案要点】
1. Init定义：在UNIX系统中，init是系统启动后第一个运行的进程，PID为1，负责启动其他所有进程，并收养孤儿进程。
2. 作用：作为守护进程持续运行，管理系统的运行级别（如单用户模式、多用户模式），并确保系统正常关闭。
3. 变体：传统System V init使用运行级别脚本，BSD init使用启动脚本，现代Linux发行版多采用systemd替代init以提高并行启动能力。
【面试角度】
回答时若能提及实际系统管理经验，如“在CentOS中通过systemctl管理服务”，能展示对现代系统的熟悉度。
【延伸知识】
init的替代品包括systemd（主流）、Upstart（Ubuntu旧版）、launchd（macOS），了解这些有助于应对不同系统环境的面试问题。
```

## Q004488

- 题型：简答
- 难度：简单

**题目**

```text
XP多用户下\"注销\"与\"切换\"的区别.
```

**答案**

```text
1、切换用户：切换用户保持当前用户登录的情况下切换到另外一个用户，对系统而言，是同时有两个用户在运行。切换用户未清空当前用户的缓存空间和注册表信息。

2、注销：注销必须先向系统发出清除现在登陆的用户的请求，清除后才可使用其他用户来登陆系统。注销清空了当前用户的缓存空间和注册表信息。
```

**解析**

```text
【核心考点】 操作系统 多用户管理
【参考答案要点】
1. 注销：结束当前用户的所有进程，清除该用户的缓存和注册表信息，返回登录界面。其他用户需重新登录。
2. 切换用户：保持当前用户会话在后台运行（进程不中断），切换到另一个用户界面。系统同时存在多个用户会话，占用更多资源。
【面试角度】
回答时可补充实际场景应用：例如管理员需要临时使用普通用户权限时用“切换用户”，而彻底释放资源时用“注销”。
【易错提示】
注意“切换用户”不会结束原用户进程，可能导致资源占用或安全风险，面试中可能考察对系统资源管理的理解。
```

## Q004492

- 题型：简答
- 难度：简单

**题目**

```text
du 和 df 的定义，以及区别？
```

**答案**

```text
df用于检查文件系统磁盘占用情况，du检查磁盘空间占用情况；

du的英文原义为“disk usage”，含义为显示磁盘空间的使用情况。该命令逐级进入指定目录的每一个子目录并显示该目录占用文件系统数据块（1024字节）的情况。若没有给出Names，则对当前目录进行统计。

df命令参数功能：检查文件系统的磁盘空间占用情况，利用所有文件系统对i节点来获取硬盘被占用了多少空间，目前还剩下多少空间等信息。
```

**解析**

```text
【核心考点】 Linux命令 磁盘管理
【题目解析】
本题考查Linux系统中两个常用磁盘管理命令的区别。df和du都用于查看磁盘空间，但侧重点不同：df从文件系统层面统计，du从目录/文件层面统计。
【参考答案要点】
1. df（Disk Free）：显示文件系统的磁盘空间使用情况，包括总容量、已用、可用、使用率、挂载点等。它从超级块读取信息，统计的是整个文件系统的空间，包括被删除但仍有进程打开的文件所占空间。
2. du（Disk Usage）：显示指定文件或目录的磁盘空间占用情况，递归统计每个子目录和文件的大小。它通过扫描文件系统计算实际使用的空间，不包括被删除但未释放的文件。
3. 主要区别：
① 统计范围：df针对整个文件系统，du针对指定路径。
② 统计方式：df读取文件系统元数据，du遍历文件。
③ 结果差异：当有文件被删除但进程未释放时，df显示的空间仍被占用，du则不会统计，导致df显示已用空间大于du总和。
【面试角度】
回答时建议结合实际排障场景，例如“当磁盘空间不足但du统计总和远小于df显示时，通常是有大文件被删除但进程未释放，可用lsof命令查找”。这能体现问题排查能力。
【易错提示】
不要混淆两者功能。df用于查看文件系统整体使用情况，du用于查看具体目录/文件大小。面试中常通过场景题考察，如“如何找出占用磁盘空间最大的目录？”应回答使用du命令。
```

```text
find和grep两个命令的区别
```

```text
find是查找文件

grep 查找的内容 文件名
```


- 难度：简单

**题目**

```text
git没有push（在本地代码仓库）和已经push后这两种场景的回滚的命令是什么？
```

**答案**

```text
git reset:：回滚本地未push的内容。回滚的历史将消失
git revert：回滚已push的内容。历史记录保留，回滚后重新生成提交记录
```

**解析**

```text
【核心考点】 Git版本控制 回滚操作
【题目解析】
本题考查Git中回滚命令的区别。本地未push的修改可用git reset撤销，但会丢失提交历史；已push的修改需用git revert，它通过创建新提交来撤销更改，保留历史记录。
【参考答案要点】
未push（本地仓库）：
git reset --hard HEAD~1：回退到上一个提交，丢弃所有更改。
git reset --soft HEAD~1：回退到上一个提交，保留更改在工作区。
已push（远程仓库）：
git revert HEAD：生成一个新提交，撤销当前提交的更改。
然后git push推送该新提交。
【面试角度】
面试中可能追问场景题，如“误提交了敏感信息怎么办？”建议回答：先用git revert撤销，再修改敏感信息后重新提交。若已push，需通知团队协调。
【易错提示】
不要对已push的历史使用git reset，否则会导致团队冲突。始终用git revert保证协作安全。
```


**答案**

```text
先通过netstat -apn，查看被占用的端口以及对应的进程，如果这个进程是我们需要的程序，在用我们就另外用一个端口；

如果这个程序目前没用了，那么就会用kill -9把这个进行杀掉 释放这个端口出来。
```

**解析**

```text
【核心考点】 Linux网络管理 端口冲突解决
【题目解析】
本题考查Linux环境下端口冲突的排查与解决能力，是测试工程师搭建环境时的常见问题。回答需体现清晰的排查思路和操作步骤。
【参考答案要点】
1. 查找占用端口的进程：使用 netstat -apn | grep 端口号 或 lsof -i:端口号，查看占用该端口的进程PID和程序名。
2. 判断进程是否必要：如果该进程是当前环境需要的（如数据库、中间件），则考虑更换端口号；如果该进程已无用或可停止，则使用 kill -9 PID 强制终止进程，释放端口。

【延伸知识】
```

```text
firewall-cmd --zone=public --add-port=8080/tcp --permanent

firewall-cmd --zone=public --query-port=8080/tcp

7.查看防火墙所有端口

firewall-cmd --zone=public --list-ports

firewall-cmd --zone=public --remove-port=8086/tcp --permanent

firewall-cmd --reload
```
