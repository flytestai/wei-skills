## Q004421

- 难度：入门

**题目**

```text
(LINUX )如何查看当前服务器的ip:
```

**答案**

```text
ifconfig 或者ifconfig -a
```

**解析**

```text
【核心考点】 Linux基础命令 网络配置
【题目解析】
本题考察Linux系统中查看IP地址的基本命令。`ifconfig`是常用的网络接口配置工具，可以显示当前网络接口的状态，包括IP地址、子网掩码等信息。使用`ifconfig -a`可以显示所有网络接口（包括未激活的）。在较新的Linux发行版中，`ip addr`或`ip a`也常被使用，但`ifconfig`仍是经典答案。

【面试角度】

【易错提示】
注意`ifconfig`在某些最小化安装的系统中可能未预装，需要安装`net-tools`包。
```

## Q004427

- 题型：简答
- 难度：入门

**题目**

```text
Ghost的主要用途和常用方法？？
```

**答案**

```text
主要用途是备份数据。常用将系统分区备份到.GHO文件中，系统出错时，可以通过这个.GHO文件来恢复系统
```

**解析**

```text
【核心考点】 系统备份与恢复 Ghost工具使用
【参考答案要点】
主要用途：Ghost是一款磁盘克隆和备份工具，主要用于将整个系统分区或硬盘备份成一个镜像文件（.GHO），以便在系统崩溃、中毒或硬件故障时快速恢复系统，减少重装系统的时间和工作量。
常用方法：
1. 备份系统：使用Ghost的“Local→Partition→To Image”功能，选择源分区（通常是C盘），指定目标路径和文件名（.GHO），选择压缩方式（Fast或High）后开始备份。
2. 恢复系统：使用Ghost的“Local→Partition→From Image”功能，选择之前备份的.GHO文件，选择目标分区（通常是C盘），确认后开始恢复，恢复完成后重启系统即可。
【面试角度】
虽然Ghost在传统运维中常用，但现代面试中更关注系统备份与恢复的通用原理，如增量备份、差异备份、快照技术等。建议在回答时补充说明Ghost的局限性（如不支持热备份、对SSD支持不佳），并提及更现代的替代方案（如Windows系统还原、Acronis True Image等），以展示知识广度。
【易错提示】
注意区分Ghost备份与普通文件备份：Ghost是扇区级克隆，会复制整个分区包括引导记录和系统文件，而文件备份只复制用户数据。此外，恢复时目标分区大小不能小于源分区，否则会导致恢复失败。
```

## Q004431

- 题型：简答
- 难度：简单

**题目**

```text
Linux 中进程有哪⼏种状态？在 ps 显⽰出来的信息中，分别⽤什么符号表⽰的？
```

**答案**

```text
Linux进程状态：

1. 运行(正在运行或在运行队列中等待)

2. 中断(休眠中, 受阻, 在等待某个条件的形成或接受到信号)

3. 不可中断(收到信号不唤醒和不可运行, 进程必须等待直到有中断发生)

4. 僵死(进程已终止, 但进程描述符存在, 直到父进程调用wait4()系统调用后释放)

5. 停止(进程收到SIGSTOP, SIGSTP, SIGTIN, SIGTOU信号后停止运行运行)

ps工具标识进程的5种状态码:
D 不可中断 uninterruptible sleep (usually IO)

R 运行 runnable (on run queue)

S 中断 sleeping

T 停止 traced or stopped

Z 僵死 a defunct (”zombie”) process
```

**解析**

```text
【核心考点】 Linux进程状态 ps命令
【参考答案要点】
Linux进程有5种主要状态，ps命令中对应符号如下：
1. 运行（R）：进程正在运行或在运行队列中等待。
2. 可中断睡眠（S）：进程在等待某条件（如I/O完成），可被信号唤醒。
3. 不可中断睡眠（D）：进程在等待I/O（如磁盘），不可被信号中断，通常用于避免数据损坏。
4. 僵死（Z）：进程已终止但父进程未回收其资源，进程描述符仍存在。
5. 停止（T）：进程收到SIGSTOP等信号后暂停执行。
【面试角度】
面试常问僵死进程的产生原因及处理，以及不可中断睡眠与可中断睡眠的区别。建议举例说明，如“使用kill -9无法杀死D状态进程”。
【延伸知识】
ps命令常用选项：ps aux显示所有进程详细信息，ps -ef以标准格式显示。top命令可实时查看进程状态及资源占用。
```

```text
参考：netstat -anp | grep port_number
```

```text
【核心考点】 Linux网络命令 端口查看
【题目解析】
本题考查Linux环境下查看端口号的常用命令。netstat是网络统计工具，结合grep过滤可快速定位特定端口。
【参考答案要点】
1. 命令：netstat -anp | grep port_number
2. 参数说明：-a显示所有连接和监听端口，-n以数字形式显示地址和端口，-p显示进程PID和名称。

【延伸知识】
```
