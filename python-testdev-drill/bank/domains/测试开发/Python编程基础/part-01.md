## Q003209

- 题型：简答
- 难度：入门

**题目**

```text
&和&&的区别
```

**答案**

```text
逻辑运算符&：& 和 && 当两边同时为true是结果才为true，区别是&&有短路效果，当左边为false时右边不再运算节省性能。
```

**解析**

```text
【核心考点】 Java基础 逻辑运算符
【题目解析】
本题考查Java中逻辑运算符&和&&的区别。两者都用于布尔表达式，当两边都为true时结果才为true。核心区别在于短路行为：&&具有短路功能，当左边为false时，右边不再计算，直接返回false；而&总是计算两边表达式。短路特性可提升性能并避免潜在异常（如空指针）。
【参考答案要点】
1. 共同点：两者都是逻辑与运算符，当左右操作数都为true时返回true。
2. 区别：&&是短路与，如果左边为false，右边不执行；&是非短路与，两边都会执行。
3. 示例：if (a != null && a.length() > 0) 安全；if (a != null & a.length() > 0) 可能抛出空指针异常。
【面试角度】
面试中常结合实际代码场景提问，如“以下代码输出什么”，考察对短路行为的理解。建议同时了解|和||的区别，以及位运算符&和|的用法。
【易错提示】
混淆逻辑与和位与运算符。&也可作为位运算符用于整数，但本题仅讨论布尔逻辑场景。
```

## Q003241

- 题型：简答
- 难度：入门

**题目**

```text
Python中局部变量和全局变量的规则是什么？
```

**答案**

```text
1、局部变量：如果在函数体内的任何位置为变量赋值，则假定它是本地的。
2、全局变量：仅在函数内引用的那些变量是隐式全局变量。
```

**解析**

```text
【核心考点】 Python变量作用域 局部变量 全局变量
【参考答案要点】
1. 局部变量：在函数体内通过赋值定义的变量，作用域仅限于该函数。函数执行结束后，局部变量被销毁。
2. 全局变量：在函数体外定义的变量，或在函数内使用 global 关键字声明的变量，作用域为整个模块。函数内若未使用 global 声明，对同名变量的赋值会创建新的局部变量，而非修改全局变量。
【面试角度】
面试中常考察变量作用域规则的实际应用，例如以下代码的输出：
x = 10
def func():
x = 20
func()
print(x) # 输出 10，因为函数内 x 是局部变量
理解 global 和 nonlocal 关键字的使用场景也是高频考点。
【易错提示】
注意：在函数内引用变量时，Python 遵循 LEGB 规则（局部→闭包→全局→内置）。如果函数内既有引用又有赋值，且变量未声明为 global，则 Python 会将其视为局部变量，可能导致 UnboundLocalError。
```

```text
Python中的反向索引是什么？
```

```text
1、Python序列可以是正数和负数的索引。对于正索引，0是第一个索引，1是第二个索引，依此类推。对于负索引，（ - 1）是最后一个索引，（ - 2）是倒数第二个索引，依此类推。
```

**解析**

```text
【核心考点】 Python基础 序列索引
【题目解析】
本题考查Python序列（如列表、字符串、元组）的索引机制。反向索引（负索引）是Python的一个特性，允许从序列末尾开始访问元素，-1表示最后一个元素，-2表示倒数第二个，依此类推。这与正向索引（从0开始）互补，简化了从尾部获取元素的操作。
【参考答案要点】
1. 定义：反向索引使用负数从序列末尾开始索引，-1指向最后一个元素。
2. 示例：对于列表lst = [10, 20, 30]，lst[-1]返回30，lst[-2]返回20。
3. 应用：常用于获取序列末尾元素，如字符串的最后一个字符。
【易错提示】
注意反向索引从-1开始，而非-0，且不能超出序列长度（如空序列使用反向索引会引发IndexError）。
【面试角度】
这是Python基础面试题，回答时建议结合代码示例说明，展示对索引机制的清晰理解。
```

## Q003246

- 难度：入门

**题目**

```text
Python中自定义的函数如何传递动态参数？
```

**答案**

```text
参考：
参数使用*args或者*kwargs
```

**解析**

```text
【核心考点】 Python函数参数 动态参数
【题目解析】
本题考查Python中动态参数传递的机制。Python支持*args和**kwargs两种形式，分别用于传递可变数量的位置参数和关键字参数。这是Python函数定义的基础知识点，常用于编写灵活的函数。
【参考答案要点】
1. 使用*args：在函数定义中使用*args，可以接收任意数量的位置参数，参数以元组形式传入。例如：def func(*args): print(args)。
2. 使用**kwargs：在函数定义中使用**kwargs，可以接收任意数量的关键字参数，参数以字典形式传入。例如：def func(**kwargs): print(kwargs)。
3. 组合使用：可以同时使用*args和**kwargs，但顺序需固定：普通参数、*args、**kwargs。例如：def func(a, *args, **kwargs)。
【面试角度】
回答时可补充实际应用场景，例如“在编写装饰器或框架时，常用*args和**kwargs传递任意参数”，体现实用性。同时可提及参数解包，如使用*list或**dict调用函数。
【易错提示】
注意*args和**kwargs只是约定名称，实际可以使用其他名称，但星号是关键。另外，位置参数和关键字参数的顺序不能颠倒，否则会引发语法错误。
```

## Q003251

- 题型：简答
- 难度：入门

**题目**

```text
Python循环体中break和 continue的区别?
```

**答案**

```text
break和continue都是用来控制循环结构的 但是break是用来结束整个循环，跳出循环体执行循环后面的语句，是跳出大循环。 continue是跳出本次循环，不执行continue后面的语句，是跳出小循环。
```

**解析**

```text
【核心考点】 Python循环控制 break continue
【题目解析】
本题考查Python中break和continue关键字的区别。两者都用于控制循环流程，但作用范围不同：break终止整个循环，continue跳过当前迭代的剩余部分。
【参考答案要点】
1. break：立即终止循环，跳出循环体执行后续代码。适用于找到目标后提前结束。
2. continue：跳过本次循环的剩余语句，进入下一次迭代。适用于忽略某些条件的情况。
【面试角度】
面试中常会要求举例说明，例如“在列表中查找元素时用break，过滤无效数据时用continue”。建议结合代码片段演示。
【易错提示】
注意break和continue在嵌套循环中的作用范围：break只终止当前最内层循环，continue只影响当前循环。
```

```text
注意pass与continue的区别：pass不改变循环流程，而continue会跳过后续代码进入下一次循环。在函数或类定义中，pass常用于占位。
```

```text
列表是可变的，可以修改、添加、删除其中的元素，但是元组是不可变的，不能修改、添加、删除其中的元素。
```

```text
Python 中各种下划线的作用?
```

```text
2. 单下划线开头，表示是保护成员，只能是类对象和子类对象能够访问
3. 双下划线开头，表示私有成员，只能是类本身可以访问
```

**解析**

```text
【核心考点】 Python命名规范 访问控制
【题目解析】

【参考答案要点】
1. 双下划线开头和结尾（__xxx__）：魔术方法，如__init__、__str__，由Python内部定义，不应自定义。
```

```text
【参考答案要点】
```

```text
class Parent:
def __init__(self, name):
```

## Q003332

- 题型：简答
- 难度：简单

**题目**

```text
python如何操作数据库的？
```

**答案**

```text
python是使用第三方库去操作数据库，不同的数据库都有对应的第三方库。
工作中，mysql用的比较多，所以在python中使用的是pymysql模块去操作的。
首先，是初始化数据库类，配置连接参数，含数据库地址、数据库名、用户名和密码，端口，编码格式，指定查询结果为字典。
其次，调用execute方法，执行sql语句。如果是对数据库进行修改，再调用commit函数提交 。
操作完成之后，调用close方法关闭数据库连接
```

**解析**

```text
【核心考点】 Python数据库操作 pymysql模块
【题目解析】
本题考查Python操作数据库的基本流程。Python通过第三方库与数据库交互，不同数据库有对应的库，如pymysql用于MySQL。操作流程通常包括连接、执行SQL、提交事务和关闭连接。
【参考答案要点】
1. 安装模块：使用pip install pymysql安装。
2. 建立连接：使用pymysql.connect()方法，传入主机、端口、用户名、密码、数据库名等参数。
3. 创建游标：通过connection.cursor()获取游标对象。
4. 执行SQL：使用cursor.execute()执行SQL语句，查询操作通过cursor.fetchall()获取结果。
5. 提交事务：对于修改操作（INSERT、UPDATE、DELETE），需调用connection.commit()提交。
6. 关闭连接：操作完成后调用cursor.close()和connection.close()释放资源。
【面试角度】
回答时建议补充异常处理和连接池等进阶内容，例如“在实际项目中，我们使用with语句确保连接自动关闭，并采用连接池提高性能”，能体现工程化思维。
【易错提示】
忘记调用commit()是常见错误，导致修改操作未生效。另外，注意SQL注入风险，应使用参数化查询而非字符串拼接。
```

## Q003333

- 题型：简答
- 难度：简单

**题目**

```text
python实现列表去重的方法
```

**答案**

```text
先通过集合去重，再转换成列表
```

**解析**

```text
【核心考点】 Python基础 列表去重
【题目解析】
本题考查Python中列表去重的常见方法。利用集合（set）的无序性和元素唯一性，可以快速去除列表中的重复元素，再将集合转换回列表即可得到去重后的结果。这是面试中非常基础且高频的问题。
【参考答案要点】
方法一：使用set去重：list(set(original_list))。注意：set会改变元素顺序，如果需保持原顺序，可使用sorted(set(original_list), key=original_list.index)。
方法二：使用循环和临时列表：遍历原列表，将不重复的元素添加到新列表中。
方法三：使用列表推导式结合字典（Python 3.7+）：list(dict.fromkeys(original_list))，可保持顺序。
【易错提示】
直接使用set()会丢失元素顺序，面试中常被追问如何保持顺序，建议掌握dict.fromkeys()或sorted()方法。
```
