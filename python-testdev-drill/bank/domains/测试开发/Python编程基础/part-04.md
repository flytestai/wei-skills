## Q003442

- 题型：简答
- 难度：较难

**题目**

```text
关于 Python 中的 intern 机制，你有了解过吗？
```

**答案**

```text
1、在运行 Python 程序的时候，会专门分配一块空白的内存空间，用来保存由数字、字母、下划线组成的字符串，也就是纯单词、字符组成的字符串，
2、这块空白的内存就被称为 字符串驻留池，也称作 大整数池；
3、所谓的 intern 机制，就是在程序运行过程中创建新的字符串的时候，首先根据这个字符串，驻留池里面查找是否这个字符串，在这个驻留池里面是否已经创建了；
4、如果有的话就已经直接拿过来用，如果没有的话就在重新创建；创建之后如果是一个纯单词字符的话，会加入到这个驻留池当中，这样的一个机制，能够避免频繁的创建和销毁；
5、这个对象能够提升我们程序的一个运行效率；
```

**解析**

```text
【核心考点】 Python 内存管理 字符串驻留 intern 机制
【参考答案要点】
1. 字符串驻留池：Python 在程序启动时分配一块内存（驻留池），用于缓存由字母、数字、下划线组成的字符串（即标识符形式的字符串）。
2. intern 机制：创建新字符串时，先检查驻留池中是否已存在相同内容的字符串。若存在，则直接返回已有对象的引用，避免重复创建；若不存在，则创建新对象并加入驻留池。
3. 作用：减少内存占用，提升字符串比较和创建效率，尤其适用于大量重复字符串的场景。
4. 注意：该机制仅对编译时确定的字符串常量（如变量名、属性名）自动生效，动态创建的字符串（如拼接结果）通常不会自动驻留，除非显式调用 sys.intern()。
【面试角度】
回答时建议结合实际代码示例说明，例如：a = 'hello'; b = 'hello'; a is b # True，并解释为什么 'hello world' 可能不被驻留。能体现对 Python 底层内存管理的理解深度。
【延伸知识】
Python 的 intern 机制与 Java 的字符串常量池类似，但实现细节不同。了解 sys.intern() 的显式用法，以及驻留对 is 比较的影响，是面试中的加分项。
```

## Q003476

- 题型：简答
- 难度：较难

**题目**

```text
合唱队描述N 位同学站成一排，音乐老师要请最少的同学出列，使得剩下的 K 位同学排成合唱队形。设KK位同学从左到右依次编号为 1，2…，K ，他们的身高分别为T_1,T_2,…,T_KT1,T2,…,TK ，若存在i(1\\leq i\\leq K)i(1≤i≤K) 使得T_1<T_2<......<T_{i-1}<T_iT1<T2<......<Ti−1<Ti 且 T_i>T_{i+1}>......>T_KTi>Ti+1>......>TK，则称这KK名同学排成了合唱队形。通俗来说，能找到一个同学，他的两边的同学身高都依次严格降低的队形就是合唱队形。例子：123 124 125 123 121 是一个合唱队形123 123 124 122不是合唱队形，因为前两名同学身高相等，不符合要求123 122 121 122不是合唱队形，因为找不到一个同学，他的两侧同学身高递减。你的任务是，已知所有N位同学的身高，计算最少需要几位同学出列，可以使得剩下的同学排成合唱队形。注意：不允许改变队列元素的先后顺序 且 不要求最高同学左右人数必须相等数据范围： 1≤n≤3000 输入描述：用例两行数据，第一行是同学的总数 N ，第二行是 N 位同学的身高，以空格隔开输出描述：最少需要几位同学出列示例1输入：8\n186 186 150 200 160 130 197 200输出：4说明：由于不允许改变队列元素的先后顺序，所以最终剩下的队列应该为186 200 160 130或150 200 160 130
```

**答案**

```text
import bisect

# 找到每一个元素从左到右的最大递增序列
def get_count(height):
# 递增序列
temp = []
# 每个元素左边的最长递增序列长度
data = []
for i in height:
if i in temp:
data.append(len(temp[:temp.index(i)]))
else:
index = bisect.bisect_left(temp, i)
if index == len(temp):
temp.append(i)
else:
temp[index] = i
data.append(len(temp[:index]))
return data

num = int(input())
height = list(map(int, input().split()))
left_order = get_count(height)
right_order = get_count(height[::-1])[::-1]
res = []
for i in range(len(left_order)):
res.append(left_order[i]+right_order[i]+1)

print(num-max(res))
```

**解析**

```text
【核心考点】 动态规划 最长递增子序列 算法设计
【题目解析】
本题考查合唱队形问题的算法实现，本质是求最长先增后减子序列的长度。核心思路是分别计算每个位置左边的最长递增子序列（LIS）长度和右边的最长递减子序列（LDS）长度，两者之和减1即为以该位置为峰顶的合唱队形最大长度，总人数减去最大长度即为最少出列人数。
【参考答案要点】
1. 算法思路：使用动态规划或贪心+二分查找（如bisect）分别计算从左到右的LIS长度数组left[i]和从右到左的LDS长度数组right[i]。
2. 计算过程：对于每个位置i，left[i]表示以i结尾的最长递增子序列长度，right[i]表示以i开头的最长递减子序列长度（等价于反向LIS）。
3. 结果计算：合唱队形最大长度 = max(left[i] + right[i] - 1)，最少出列人数 = N - 合唱队形最大长度。
4. 代码实现：使用bisect模块维护递增序列，时间复杂度O(N log N)，优于传统DP的O(N²)。
【面试角度】
此类算法题考察动态规划与贪心策略的综合应用，面试中需注意边界条件（如身高相等时不能构成严格递增/递减），并能够清晰解释算法的时间复杂度和空间复杂度优化。
【延伸知识】
该问题也可通过线段树或树状数组优化，但面试中掌握贪心+二分查找的O(N log N)解法已足够。类似问题还有“最长回文子序列”、“最长公共子序列”等，建议系统学习LIS系列问题。
```

## Q003587

- 题型：简答
- 难度：较难

**题目**

```text
生成器和迭代器是什么
```

**答案**

```text
迭代器是一个更抽象的概念，任何对象，如果它的类有 next 方法和 iter 方法返回自己本身，对于 string、list、
dict、tuple 等这类容器对象，使用 for 循环遍历是很方便的。在后台 for 语句对容器对象调用 iter()函数，iter()
是 python 的内置函数。iter()会返回一个定义了 next()方法的迭代器对象，它在容器中逐个访问容器内元素，next()
也是 python 的内置函数。在没有后续元素时，next()会抛出一个 StopIteration 异常。

生成器（Generator）是创建迭代器的简单而强大的工具。它们写起来就像是正规的函数，只是在需要返回数
据的时候使用 yield 语句。每次 next()被调用时，生成器会返回它脱离的位置（它记忆语句最后一次执行的位置
和所有的数据值）

区别：生成器能做到迭代器能做的所有事,而且因为自动创建了 iter()和 next()方法,生成器显得特别简洁,而且
生成器也是高效的，使用生成器表达式取代列表解析可以同时节省内存。除了创建和保存程序状态的自动方法,当
生成器器终结时,还会自动抛出 StopIteration 异常。
```

**解析**

```text
【核心考点】 Python迭代器 生成器
【题目解析】
本题考察Python中迭代器和生成器的概念辨析。迭代器是实现了__iter__()和__next__()方法的对象，用于逐个访问元素；生成器是使用yield关键字的函数，自动创建迭代器，简化代码。
【参考答案要点】
1. 迭代器：任何实现了__iter__()和__next__()方法的对象，用于遍历容器。for循环内部调用iter()获取迭代器，然后不断调用next()直到StopIteration异常。
2. 生成器：使用yield关键字的函数，每次调用返回一个值并暂停状态。生成器是迭代器的一种，更简洁，常用于处理大数据流。
【面试角度】
面试中常要求手写生成器示例，如斐波那契数列生成器，并解释yield与return的区别。理解生成器节省内存的特性（惰性求值）是加分项。
【延伸知识】
Python中列表推导式与生成器表达式的区别：列表推导式返回列表，占用内存；生成器表达式返回生成器对象，按需计算。
```

## Q003606

- 题型：简答
- 难度：较难

**题目**

```text
简要描述Python的垃圾回收机制
```

**答案**

```text
Python在内存中存储了每个对象的引用计数（reference count）。如果计数值变成0，那么相应的对象就会小时，分配给该对象的内存就会释放出来用作他用。

偶尔也会出现引用循环（reference cycle）。垃圾回收器会定时寻找这个循环，并将其回收。举个例子，假设有两个对象o1和o2，而且符合o1.x == o2和o2.x == o1这两个条件。如果o1和o2没有其他代码引用，那么它们就不应该继续存在。但它们的引用计数都是1。

Python中使用了某些启发式算法（heuristics）来加速垃圾回收。例如，越晚创建的对象更有可能被回收。对象被创建之后，垃圾回收器会分配它们所属的代（generation）。每个对象都会被分配一个代，而被分配更年轻代的对象是优先被处理的。
```

**解析**

```text
【核心考点】 Python垃圾回收 内存管理
【参考答案要点】
1. 引用计数：Python为每个对象维护引用计数，当计数降为0时，对象被销毁，内存释放。
2. 循环引用处理：引用计数无法处理循环引用（如o1.x = o2且o2.x = o1），此时引用计数均为1，但无外部引用，需要垃圾回收器介入。
3. 分代回收：Python使用启发式算法，将对象按创建时间分为不同“代”，越晚创建的对象越可能被回收，回收器定期扫描并回收循环引用。
【面试角度】
回答时建议结合实际编码经验，例如“在开发中，我通过__del__方法观察对象销毁，验证引用计数机制”，能体现深入理解。
【延伸知识】
Python的垃圾回收机制还包括弱引用（weakref模块）和手动触发回收（gc.collect()），面试中可补充以展示全面性。
```

## Q003609

- 题型：简答
- 难度：较难

**题目**

```text
简述Python垃圾回收机制？
```

**答案**

```text
python的垃圾回收机制主要是引用计数，标记清除和分代回收三种机制。

引用计数的原理是为每个对象维护一个`ob_ref`,用来记录当前对象被引用的次数，也就是来追踪到底有多少引用指向这个对象。当指向该对象的内存的引用计数为0的时候，该内存将会被回收。

引用计数有个明显的缺点就是无法解决循环引用问题。A和B相互引用而再没有外部引用A和B中的任何一个，它们的计数都为1，但显然应该被回收。

为了解决这个问题，python的垃圾回收机制引入了标记清除算法，它是一种基于追踪回收技术实现的垃圾回收算法。它分两个阶段：第一个阶段是标记阶段，在这个阶段会为所有的"活动对象"打上标记，第二阶段是把那些没有标记的对象"非活动对象"进行回收。

标记阶段是通过对象之间通过引用连接在一起构成的有向图来区分活动对象和非活动对象的。对象构成这个有向图的节点，引用关系构成这个有向图的边。从根对象出发，沿着有向边遍历对象，可达的对象标记为活动对象，不可达的对象就是要被清除的非活动对象。根对象就是全局变量，调用栈，寄存器。

python什么时候会进行这个标记过程呢？为了性能和效率考虑，又引入了分代回收的机制。

简单来说就是将所有对象按照引用次数分为3代。刚创建的对象都会被放入零代链表中，当这个对象的引用计数随着程序的运行超过了某个阈值之后，会被从零代放入更老一代。越新的代，进行标记的频率就越高，当检查到有循环引用时，会将相互引用的对象的引用计数都减1，如果引用计数为0则销毁该对象。
```

**解析**

```text
【核心考点】 Python垃圾回收 内存管理
【题目解析】
本题考查Python的垃圾回收机制，包括引用计数、标记清除和分代回收。需要理解每种机制的原理和优缺点。
【参考答案要点】
1. 引用计数：每个对象维护ob_ref计数，为0时回收。缺点是无法处理循环引用。
2. 标记清除：从根对象开始标记活动对象，清除未标记对象，解决循环引用。
3. 分代回收：将对象按存活时间分为三代，减少全量扫描频率，提升性能。
【面试角度】
回答时建议对比其他语言（如Java的GC），并说明Python GC的适用场景，能展示知识广度。
【易错提示】
常见错误是只回答引用计数，忽略标记清除和分代回收，或混淆循环引用与内存泄漏的概念。
```

## Q003622

- 题型：简答
- 难度：较难

**题目**

```text
给定一个列表，找到其中第k大的元素。
```

**答案**

```text
import random

def quick_select(nums, k):
pivot = random.choice(nums)
left = [x for x in nums if x > pivot]
mid = [x for x in nums if x == pivot]
right = [x for x in nums if x < pivot]

if k <= len(left):
return quick_select(left, k)
elif k <= len(left) + len(mid):
return mid[0]
else:
return quick_select(right, k - len(left) - len(mid))

nums = [3, 2, 1, 5, 6, 4]
print(quick_select(nums, 2))
```

**解析**

```text
【核心考点】 快速选择算法 分治思想 时间复杂度
【参考答案要点】
使用快速选择算法（Quick Select）实现，基于快速排序的分治思想，平均时间复杂度O(n)。算法步骤：
1. 选择基准：随机选择一个元素作为pivot。
2. 分区：将列表分为三部分：大于pivot、等于pivot、小于pivot。
3. 递归选择：若k小于等于大于pivot部分的长度，则在大于部分递归查找第k大；若k在大于和等于部分范围内，则返回pivot；否则在小于部分递归查找第k-len(left)-len(mid)大。
【面试角度】
面试中需注意边界条件处理，如k值超出列表范围、列表为空等。同时可讨论与排序后取第k大的性能差异（排序O(nlogn) vs 快速选择O(n)），体现算法优化意识。
【延伸知识】
快速选择算法在最坏情况下时间复杂度为O(n²)，可通过随机化pivot避免。此外，堆排序也可用于求解第k大元素（维护大小为k的最小堆），时间复杂度O(nlogk)，适用于数据流场景。
```

```text
【题目解析】
```

```text
【参考答案要点】
算法步骤：
1. 统计每个数字出现的次数，记录需要删除的总次数（每个数字超过2次的部分）。
2. 使用栈遍历字符串，对于当前数字：
- 如果栈不为空，且栈顶数字小于当前数字，且栈顶数字还有删除配额（即该数字出现次数超过2次且尚未删除足够），则弹出栈顶，并减少该数字的删除配额。

3. 遍历结束后，如果还有删除配额，从栈顶依次删除（因为此时栈中数字已是非递增序列，删除末尾不影响最大值）。
4. 将栈中数字拼接成字符串返回。
```
