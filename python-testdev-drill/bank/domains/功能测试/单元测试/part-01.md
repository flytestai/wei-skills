## Q002298

- 题型：填空
- 难度：简单
- 解析：AI 补全（原数据缺失解析）

**题目**

```text
单元测试中对类进行三级测试①
```

**答案**

```text
方法内部测试、方法间测试、类内部测试
```

**解析**

```text
【核心考点】面向对象单元测试的层次。
【题目解析】对类做单元测试可分三个层次：方法内部测试，验证单个方法的逻辑与边界；方法间测试，验证同一类中方法调用与状态传递；类内部测试，验证类整体行为及对外接口。由细到粗逐层推进。
【答题要点】
1. 依次为方法内部测试、方法间测试、类内部测试。
2. 方法级关注分支与边界。
3. 类级关注状态变化和接口契约。
【面试提示】可补充通过桩和驱动隔离外部依赖。
```

## Q002299

- 题型：填空
- 难度：简单
- 解析：AI 补全（原数据缺失解析）

**题目**

```text
单元测试的策略① 。
```

**答案**

```text
自顶向下的单元测试策略、自底向上的单元测试策略和孤立的单元测试策略
```

**解析**

```text
【核心考点】单元测试的驱动策略。
【题目解析】单元测试策略包括自顶向下、自底向上和孤立测试。自顶向下借助桩模拟下层模块，自底向上先用驱动调用已测下层，孤立策略则为被测单元单独构造桩和驱动，尽量排除依赖干扰。
【答题要点】
1. 三种策略要完整说出。
2. 自顶向下多用桩，自底向上多用驱动。
3. 孤立策略适合依赖复杂、需尽早验证的场景。
【面试提示】可比较三种策略的成本与缺陷发现时机。
```
