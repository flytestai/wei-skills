```text
在WINDOWS2000 SERVER上，用于在WEB上发布BUGZILLA的服务名称为？（）
```

**选项**

```text
A. FTP
B. SMTP
C. TELNET
D. IIS
```

**答案**

```text
D
```

**正确选项**

```text
D. IIS
```

**解析**

```text
【核心考点】 Windows 服务 Bugzilla 部署
【题目解析】
Bugzilla 是基于 Web 的缺陷跟踪系统，需要在 Web 服务器上运行。在 Windows 2000 Server 上，IIS（Internet Information Services）是微软自带的 Web 服务器，用于发布 Web 应用。
【选项解析】
✓ D. IIS — 正确。IIS 是 Windows 平台的标准 Web 服务器，用于托管 Bugzilla 等 Web 应用。

【易错提示】
注意区分服务类型：Web 发布需要 Web 服务器（如 IIS、Apache），而非协议服务（如 FTP、SMTP）。
```

```text
【参考答案要点】
1. 请求前断点（Before Request）：在请求发送到服务器之前拦截，可以修改请求头、请求参数、Cookie等数据，然后发送修改后的请求，用于测试服务器对异常或边界数据的处理。
2. 响应后断点（After Response）：在服务器返回响应但客户端尚未接收时拦截，可以修改响应状态码、响应头、响应体等数据，然后返回给客户端，用于测试客户端对异常或特殊响应的处理。
3. 操作步骤：在Fiddler中设置断点规则（如菜单栏Rules→Automatic Breakpoints→Before Requests/After Responses），或通过命令行输入bpu/bpafter设置特定URL的断点。
【面试角度】
回答时建议结合实际项目场景举例，例如“在测试支付接口时，使用请求前断点修改金额参数，验证后端是否校验；使用响应后断点模拟超时响应，验证前端超时处理逻辑”，能体现实战能力。
【易错提示】
注意区分请求前断点和响应后断点的应用场景，面试中常要求分别说明用途和操作。
```

## Q002249

- 题型：简答
- 难度：较难

**题目**

```text
JMeter二次开发主要包含哪些内容或组件的开发？
```

**答案**

```text
主要是下面几个方向：
1、自定义函数；2、自定义组件（如取样器、配置元件等）；3、基于引擎；4、完整的开发
```

**解析**

```text
【核心考点】 JMeter 二次开发 扩展性
【题目解析】
本题考查JMeter的扩展能力，JMeter基于Java开发，提供了丰富的扩展接口，允许用户自定义组件以满足特定测试需求。二次开发主要涉及编写Java代码实现JMeter的抽象类或接口，并打包为jar文件放入lib/ext目录。
【参考答案要点】
1. 自定义函数（Function）：实现Function接口，用于生成动态数据（如随机数、时间戳）。
2. 自定义取样器（Sampler）：继承AbstractSampler，实现特定协议的请求发送和响应处理。
3. 自定义配置元件（Config Element）：实现ConfigTestElement，用于设置测试参数。
4. 自定义前置/后置处理器（Pre/Post Processor）：实现SampleListener，在请求前后执行逻辑。
5. 自定义断言（Assertion）：实现Assertion接口，验证响应结果。
6. 自定义监听器（Listener）：实现SampleListener，收集和展示测试结果。
【面试角度】
面试官关注对JMeter架构的理解和实际开发经验。可举例说明：如开发一个自定义取样器用于测试WebSocket协议，或开发一个函数用于生成加密签名。建议提及使用Maven管理依赖和打包过程。
【延伸知识】
JMeter还支持通过Groovy脚本进行轻量级扩展，无需编译Java代码，适合快速原型验证。了解JMeter的插件机制（如JMeter Plugins Manager）也有助于扩展。
```
