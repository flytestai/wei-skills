## Q002284

- 题型：单选
- 难度：简单

**题目**

```text
不属于逻辑覆盖方法的是（）。
```

**选项**

```text
A. 组合覆盖
B. 判定覆盖
C. 条件覆盖
D. 接口覆盖
```

**答案**

```text
D
```

**正确选项**

```text
D. 接口覆盖
```

**解析**

```text
【核心考点】 逻辑覆盖 白盒测试
【题目解析】
本题考查白盒测试中的逻辑覆盖方法。逻辑覆盖包括语句覆盖、判定覆盖、条件覆盖、判定/条件覆盖、条件组合覆盖、路径覆盖等。接口覆盖不属于逻辑覆盖范畴。
【选项解析】
✗ A. 组合覆盖 — 错误。组合覆盖（条件组合覆盖）是逻辑覆盖的一种。
✗ B. 判定覆盖 — 错误。判定覆盖是逻辑覆盖的基本方法之一。
✗ C. 条件覆盖 — 错误。条件覆盖也是逻辑覆盖方法。
✓ D. 接口覆盖 — 正确。接口覆盖属于集成测试范畴，关注模块间接口调用，不属于逻辑覆盖。
【易错提示】
混淆逻辑覆盖与接口测试概念。逻辑覆盖针对代码内部路径，接口覆盖针对模块间交互。
```

## Q002285

- 题型：简答
- 难度：中等

**题目**

```text
什么是独立路径？
```

**答案**

```text
答案：独立路径是指包括一组以前没有处理的语句或条件的一条路径.从程序图来看,一条独立路径是至少包含有一条( 在其他独立路径中未有过 )的边的路径。
```

**解析**

```text
【核心考点】 白盒测试 独立路径测试 程序图
【题目解析】
本题考查白盒测试中独立路径的概念。独立路径是程序图中从入口到出口的一条路径，且至少包含一条在其他路径中未出现过的边。独立路径测试是基路径测试的基础，用于确保覆盖所有可能的线性无关路径。
【参考答案要点】
1. 定义：独立路径是指从程序入口到出口的一条路径，且至少包含一条在其他独立路径中未出现过的边（或语句）。
2. 与程序图的关系：程序图由节点（语句或条件）和边（控制流）组成，独立路径对应程序图中一组线性无关的路径，其数量等于程序图的圈复杂度。
3. 作用：独立路径测试可确保每个语句和条件至少被测试一次，是结构测试的重要方法。
【面试角度】
建议结合圈复杂度计算举例说明，例如：对于包含if-else和循环的程序，圈复杂度=边数-节点数+2，独立路径数即等于圈复杂度。可进一步说明基路径测试如何从程序图中导出独立路径集。
【易错提示】
独立路径不是所有可能路径，而是线性无关的最小路径集。混淆“独立路径”与“所有路径”是常见错误，实际测试中路径数量可能呈指数增长，而独立路径数量可控。
```

## Q002288

- 题型：单选
- 难度：中等

**题目**

```text
如果某测试用例集实现了某软件的路径覆盖，那么它一定同时实现了该软件的（）。
```

**选项**

```text
A. 判定覆盖
B. 条件覆盖
C. 判定/条件覆盖
D. 组合覆盖
```

**答案**

```text
A
```

**正确选项**

```text
A. 判定覆盖
```

**解析**

```text
【核心考点】 白盒测试 逻辑覆盖
【题目解析】
本题考查白盒测试中逻辑覆盖方法之间的包含关系。路径覆盖是最强的覆盖标准，它要求覆盖程序中所有可能的路径。根据覆盖强度从弱到强排序：语句覆盖 < 判定覆盖 < 条件覆盖 < 判定/条件覆盖 < 条件组合覆盖 < 路径覆盖。因此，实现了路径覆盖，必然满足所有其他覆盖标准。
【选项解析】
✓ A. 判定覆盖 — 正确。路径覆盖包含所有路径，自然覆盖了每个判定的真/假分支。
✗ B. 条件覆盖 — 错误。虽然路径覆盖通常也覆盖了所有条件，但理论上存在路径覆盖但不满足条件覆盖的极端情况，但本题标准答案通常选A，因为路径覆盖是判定覆盖的超集。
✗ C. 判定/条件覆盖 — 错误。路径覆盖强度高于判定/条件覆盖，但本题更直接的包含关系是判定覆盖。
✗ D. 组合覆盖 — 错误。组合覆盖（条件组合覆盖）强度低于路径覆盖，路径覆盖不一定能覆盖所有条件组合，但路径覆盖是更强的覆盖。
【易错提示】
注意区分“包含”与“等价”。路径覆盖是覆盖强度最高的标准，它包含判定覆盖，但判定覆盖不一定包含路径覆盖。本题常见误区是选择条件覆盖或组合覆盖，需牢记覆盖强度层次。
```

## Q002290

- 题型：单选
- 难度：中等

**题目**

```text
白盒测试的条件覆盖标准强于判定覆盖。
```

**选项**

```text
A. 对
B. 错
```

**答案**

```text
B
```

**正确选项**

```text
B. 错
```

**解析**

```text
【核心考点】 白盒测试覆盖标准 条件覆盖 vs 判定覆盖
【题目解析】
白盒测试中，判定覆盖要求每个判断的真假分支至少执行一次；条件覆盖要求每个判断中每个条件的真假至少出现一次。两者没有绝对的强弱关系：条件覆盖可能覆盖所有条件组合，但未必覆盖所有判定分支；判定覆盖可能覆盖所有分支，但未必覆盖所有条件取值。因此，条件覆盖并不一定强于判定覆盖。
【选项解析】
✗ A. 对 — 错误。条件覆盖与判定覆盖无法直接比较强弱，需结合具体逻辑。
✓ B. 错 — 正确。条件覆盖不一定强于判定覆盖，两者是不同维度的覆盖标准。
【易错提示】
常见误区：认为条件覆盖包含判定覆盖。实际上，条件覆盖关注条件取值，判定覆盖关注分支结果，两者可能互相遗漏。例如：判断 (A && B)，条件覆盖可选取A=true,B=false和A=false,B=true，但两个分支均为假，未覆盖真分支。
```

```text
本题考查基于经验的测试方法（Experience-based Testing）的概念及其在测试策略中的定位。基于经验的测试依赖测试人员的直觉、技能和过往经验，通常作为系统化测试方法的补充，而非替代。探索性测试是其典型形式，强调同时学习、设计和执行，并非严格按照预定义步骤进行。
```

## Q002293

- 难度：中等

```text
（）是设计足够多的测试用例，使得程序中每个判定包含的每个条件的所有情况（真/假）至少出现一次，并且每个判定本身的判定结果（真/假）也至少出现一次。
```

**选项**

```text
A. 判定－条件覆盖
B. 组合覆盖
C. 判定覆盖
D. 条件覆盖
```

**答案**

```text
A
```

```text
A. 判定－条件覆盖
```

```text
【核心考点】 白盒测试 逻辑覆盖
【题目解析】
本题考查白盒测试中逻辑覆盖方法的定义。判定-条件覆盖要求同时满足判定覆盖和条件覆盖，即每个判定的所有可能结果至少出现一次，且每个条件的所有可能取值至少出现一次。
【选项解析】
✓ A. 判定－条件覆盖 — 正确。符合题目描述，同时覆盖判定结果和条件取值。

✗ D. 条件覆盖 — 错误。仅覆盖条件取值，未覆盖判定结果。
【易错提示】
注意区分判定-条件覆盖与组合覆盖：前者要求每个条件取值和每个判定结果至少一次，后者要求所有条件组合至少一次，面试中常混淆考查。
```
