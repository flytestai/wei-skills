## Q007470

- 题型：简答
- 难度：中等

**题目**

```text
在使用大语言模型（LLM）进行测试时，提示词的设计对测试结果有重要影响。你会如何设计有效的提示词来验证模型的功能？
```

**答案**

```text
设计有效的提示词需要明确测试目标、提供具体输入和预期输出、添加约束条件和设置测试场景。
```

**解析**

```text
【核心考点】 任务目标 输入输出约束 场景覆盖 格式验收
【题目解析】
验证 LLM 功能时，提示词要包含任务类型、输入样例、输出格式、长度/风格约束和禁止项。应设计正常、边界、恶意、冲突指令等多类样例，检查模型是否遵循格式、拒绝违规请求并保持稳定。
【易错提示】
不要用一两个惊艳 demo判断模型能力。LLM 测试必须批量样例 + 失败分析。
```

## Q007471

- 题型：简答
- 难度：中等

**题目**

```text
如何测试AI模型的行为一致性？例如，对于一个文本分类模型，如何设计测试用例验证其在不同输入下的输出稳定性？
```

**答案**

```text
测试AI模型的行为一致性需要设计多组测试用例，验证模型在不同输入、不同时间、不同环境下的输出稳定性。
```

**解析**

```text
【核心考点】 同义输入 多轮复测 环境变化 微扰动测试
【题目解析】
测试一致性可设计语义相近输入、不同时间段/不同环境重复执行、对输入做轻微扰动（标点、同义词替换）观察分类是否异常波动。对文本分类模型，应允许合理变化但关键类别不能随意漂移。
【易错提示】
不要要求所有相似句子都输出同一个标签而不考虑语境差异。一致性测试要基于业务可接受范围设计阈值。
```

## Q007472

- 题型：简答
- 难度：中等

**题目**

```text
针对AI模型，你会如何设计边界情况测试？例如，对于一个图像识别模型，边界情况可能包括哪些？
```

**答案**

```text
针对AI模型设计边界情况测试需要考虑各种极端场景，对于图像识别模型，边界情况包括模糊图像、光照异常图像、遮挡图像、变形图像和异常场景图像。
```

**解析**

```text
【核心考点】 模糊图像 光照异常 遮挡变形 异常场景
【题目解析】
图像模型边界包括：模糊、过暗/过亮、遮挡、拉伸变形、未见过的背景/物体。测试目标是验证模型在极端条件下是否仍可用，或能否安全降级，而不是只测清晰标准样本。
【易错提示】
只测干净样本库会高估模型真实表现。线上环境远比实验室复杂。
```
