## Q007332

- 题型：简答
- 难度：简单

**题目**

```text
什么是插入排序？
```

**答案**

```text
插入排序的基本操作就是将一个数据插入到已经排好序的有序数据中，从而得到一个新的、个数加一的
有序数据，算法适用于少量数据的排序，时间复杂度为 O(n^2)。是稳定的排序方法。插入算法把要排序的数
组分成两部分：第一部分包含了这个数组的所有元素，但将最后一个元素除外（让数组多一个空间才有插入
的位置），而第二部分就只包含这一个元素（即待插入元素）。在第一部分排序完成后，再将这个最后元素
插入到已排好序的第一部分中
```

**解析**

```text
【核心考点】 排序算法 插入排序
【参考答案要点】
插入排序是一种简单直观的排序算法，其基本思想是将一个待排序的元素插入到已经排好序的序列中，从而得到一个新的、长度增加1的有序序列。适用于数据量较小的情况，时间复杂度为 O(n²)，是一种稳定的排序算法。
算法步骤：
1. 将数组分为已排序部分和未排序部分，初始时已排序部分只包含第一个元素。
2. 从未排序部分取出第一个元素，与已排序部分的元素从后向前比较，找到合适位置插入。
3. 重复步骤2，直到所有元素都插入到已排序部分。
【面试角度】
回答时，可以结合手写代码或伪代码演示插入排序的实现过程，并说明其适用场景（如小规模数据或基本有序的数据）。同时，可以对比插入排序与选择排序、冒泡排序的异同，展示对排序算法体系的掌握。
【易错提示】
注意插入排序是稳定的排序算法，而选择排序是不稳定的。另外，插入排序在数据基本有序时效率较高，接近 O(n)，这是其优势之一。
```

```text
写出你所知道的3种常用的排序方法，并用其中一种方法设计出程序为数组a[100]排序。
```

```text
冒泡排序
1、比较相邻的第一个和第二个数，如果第一个比第二个大，相互交换
2、继续比较后边每一个相邻元素，从第一个到最后一个，使得这次排序后最后一个是最大的。
3、重复步骤12，最后一个除外
4、重复步骤123，直到结束。

public static void main(String[] args) {
int arr[] = {3,6,8,5,5,7,4,1,9,2,8};
for (int i = 0; i < arr.length-1; i++) {
for (int j = 0; j < arr.length-i-1; j++) {
if (arr[j] > arr[j+1]){
int temp = arr[j+1];
arr[j+1] = arr[j];
arr[j] = temp;
}
}
}
System.out.println(Arrays.toString(arr));
}

选择排序
1、在未排序的序列中寻找最小（最大）的数，放到第一个位置
2、重复第一步，将找到的最小（最大）的数，放到未排序序列的第一个位置。
3、重复上面的步骤，直到排序完成。

minIndex = j;
}
}
if (minIndex != i){//将最小值放在未排序序列的第一位
int temp = arr[i];
arr[i] = arr[minIndex];
arr[minIndex] = temp;
}
}
System.out.println(Arrays.toString(arr));
}

插入排序
1、将序列的第一个元素认为已经排过序了，从下一个元素开始；
2、将下一个元素取出，与后往前的向以排过序的元素比较，如果已排序的这个数比取出的数要大，则将这个已排序的数向后移一位。
3、重复第二步，取出的元素继续往前比较，直到找到找到已排序的元素比它小，将取出的数插入该位置后边
4、重复上面的步骤，直到排序完成。

public static void main(String[] args) {
int arr[] = {3,6,8,5,5,7,4,1,9,2,8};
for (int i = 1; i < arr.length; i++) {
int preIndex = i-1;//认为i-1的元素已经排序
int getOut = arr[i];//将第i个元素取出与前边的数相比较
while (preIndex>=0 && getOut<arr[preIndex]){//如果取出的元素小于前边的元素，前边元素往后移一位
arr[preIndex+1] = arr[preIndex];
preIndex -= 1;
}
arr[preIndex+1] = getOut;//前边的数小于取出的数，将取出的数插入中间
}
System.out.println(Arrays.toString(arr));
}

二分排序 (Binary Insertion Sort)：二分排序算法的主要思想是将待排序的数据分为已排序和未排序两个部分，首先将第一个元素看作已排序部分，然后从第二个元素开始逐个插入到已排序部分中的适当位置，直到所有元素都被插入。这个过程的实现方式是利用二分查找算法来搜索已排序部分中的位置。因为二分排序算法的插入操作使用了二分查找算法，所以其时间复杂度为O(n log n)。

希尔排序 (Shell Sort)：希尔排序算法是对插入排序算法的优化，它的主要思想是将待排序的数据分组，对每组进行插入排序，然后逐步缩小分组的大小，直到分组大小为1，即完成排序。分组的大小通常按照某个增量序列来确定，比如使用Knuth序列来确定，相对于插入排序算法来说，希尔排序算法可以更快地将最小的元素移动到正确的位置上。希尔排序算法时间复杂度的最坏情况是O(n^2)。

总的来说，二分排序算法的实现简单，但需要进行二分查找，在数据量较大时其时间复杂度表现更好；希尔排序算法则是对插入排序的优化，其时间复杂度虽然没有达到O(n log n)，但比插入排序要好很多，对于中小规模的数据集，希尔排序算法表现相对较好
```

**解析**

```text
【核心考点】 排序算法 二分排序 希尔排序
【参考答案要点】
二分排序（Binary Insertion Sort）：是插入排序的改进版，利用二分查找在已排序部分中定位插入位置，减少比较次数，但移动次数不变，时间复杂度为 O(n log n)（比较次数），整体仍为 O(n²)。
希尔排序（Shell Sort）：是插入排序的优化，通过分组（按增量）进行插入排序，逐步缩小增量至1，使数组部分有序，最终完成排序。时间复杂度取决于增量序列，平均约 O(n^1.3)。
【面试角度】
回答时建议结合实际应用场景，如希尔排序适用于中等规模数据，二分排序适用于比较操作代价高的场景。同时可提及稳定性：二分排序稳定，希尔排序不稳定。
【延伸知识】
希尔排序的增量序列选择（如 Hibbard、Sedgewick）会影响性能，面试中可深入讨论。
```
