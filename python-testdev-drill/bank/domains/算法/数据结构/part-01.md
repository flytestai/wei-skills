## Q007368

- 题型：简答
- 难度：简单

**题目**

```text
数组，列表，队列区别？
```

**答案**

```text
数组是最最基本的数据结构，数组是使用一块连续的内存空间保存数据，保存的数据的个数在分配内存的时候就是确定的。数组可以在任意位置插入或者删除数据，插入或删除的时候后面的数据全部需要移动，移动的数据还是和数据个数有关。 数组有一维数组和二维数组。
队列可以用数组和链表来实现，队列只允许在队尾添加数据，在对头删除数据。还有一种双端队列，在两端都可以插入和删除。
列表是一种数据项构成的有限序列,即按照一定的线性顺序,排列而成的数据项的集合,在这种数据结构上进行的基本操作包括对元素的的查找,插入,和删除，由此可见列表和数组的本质区别。列表是数据集合的统称，而数组是列表在结构上的具体表现形式。
```

**解析**

```text
【核心考点】 数据结构基础 数组 队列 列表
【题目解析】
本题考察对基本数据结构的理解。数组是连续内存空间存储固定大小元素，支持随机访问；队列是先进先出（FIFO）结构，允许在队尾添加、队头删除；列表是抽象概念，表示线性序列，数组是列表的一种实现方式。
【参考答案要点】
1. 数组：连续内存空间，大小固定，支持随机访问，插入/删除需移动元素。
2. 队列：FIFO结构，可用数组或链表实现，只允许队尾插入、队头删除。
3. 列表：线性序列的抽象，支持查找、插入、删除，数组是列表的一种具体实现。
【面试角度】
回答时强调数组和队列的底层实现差异，例如“数组插入需要移动元素，而队列通过指针操作避免移动”，可展示对性能的理解。
【易错提示】
容易混淆列表和数组的概念，注意列表是抽象数据类型，数组是具体实现。面试中可能追问链表与数组的区别。
```

```text
【参考答案要点】
提供的Python代码存在错误：递归调用未返回值，且边界处理不完整。正确实现如下：
def binary_search(arr, value, left, right):
if left > right:
return -1
mid = (left + right) // 2
if arr[mid] == value:
return mid
elif arr[mid] > value:
return binary_search(arr, value, left, mid-1)
else:
return binary_search(arr, value, mid+1, right)
```

```text
left = 0
max_len = 0
for right, ch in enumerate(s):
if ch in char_index and char_index[ch] >= left:
left = char_index[ch] + 1
char_index[ch] = right
max_len = max(max_len, right - left + 1)
return max_len
【面试角度】
```

**答案**

```text
def work(arr):
new_list = []
for i in arr:
new_list += i
new_list.sort(reverse=True)
li = new_list[::2]
li1 = new_list[1::2]
li1.sort()
li2 = li + li1
res = [li2[i:i + 5] for i in range(0, len(li2), 5)]
return res

if __name__ == '__main__':
```
