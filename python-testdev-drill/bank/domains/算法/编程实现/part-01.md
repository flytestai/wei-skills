
**答案**

```text
# 用 python 写个冒泡排序
a = [1, 3, 10, 9, 21, 35, 4, 6]
for j in range(1,len(a)):
for i in range(0,len(a)-j):
# print(i) # 前一位数 > 后一位数。交换位置。
if a[i] > a[i+1]:
a[i],a[i+1] = a[i+1],a[i]
print(a)
```

```text
def bubble_sort(alist):
n = len(alist)
for i in range(n-1):
for j in range(n-i-1):
if alist[j]>alist[j+1]:
alist[j],alist[j+1] = alist[j+1],alist[j]
return alist
```

**答案**

```text
content = input()

chars = []
chars_index = []
no_chars = []
for i, c in enumerate(content):

chars_index.append(i)

def sort_char(value):
return value[0].lower()

chars.sort(key=sort_char)

for item in no_chars:
```

## Q007392

- 题型：简答
- 难度：中等

**题目**

```text
给定一个列表和一个目标值，请编写一个函数来找出列表中所有两数之和等于目标值的数对。
```

**答案**

```text
def two_sum(nums: list, target: int) -> list:
d = {}
res = []
for i, num in enumerate(nums):
if target - num in d:
res.append([d[target - num], i])
d[num] = i
return res

nums = [2, 7, 11, 15, 3, 6, 8]
target = 9
print(two_sum(nums, target)) # [[0, 1], [4, 5]]
```

**解析**

```text
【核心考点】 算法基础 哈希表 Python编程
【题目解析】
这是一道经典的算法题，考察候选人对哈希表（字典）的应用能力。要求找出所有两数之和等于目标值的数对，而非仅返回一个。使用哈希表存储已遍历元素及其索引，可以在O(n)时间复杂度内完成。
【参考答案要点】
使用一个字典记录每个数字及其索引。遍历列表时，检查目标值与当前值的差是否已在字典中。若存在，则记录该数对。注意：需处理重复元素，确保每个数对只被记录一次（通常按索引顺序）。
示例代码：
def two_sum(nums, target):
d = {}
res = []
for i, num in enumerate(nums):
if target - num in d:
res.append([d[target - num], i])
d[num] = i

对于输入 nums = [2, 7, 11, 15, 3, 6, 8], target = 9，输出 [[0, 1], [4, 5]]。
【面试角度】
面试中除了写出代码，还需讨论时间复杂度（O(n)）和空间复杂度（O(n)）。可进一步探讨如果列表有序，如何用双指针优化空间复杂度。
【易错提示】
容易忽略重复元素导致重复记录，或忘记在遍历前将当前元素加入字典（应在检查后再加入，避免使用自身）。
```

```text
给定一个整数数组nums和一个目标值m，请你在该数组中找出和为目标值的那个两个整数，并返回他们的数据下标。数据中同一个元素不能使用两遍。\n比如：nums=[1,2,2,3,4,5]，m=6 返回结果为：0,5 1,4 或者 0,5 2,4
```

**答案**

```text
nums = [1,2,2,3,4,5,1,3]
m = 6
items = []
for index in range(len(nums)):
for sub in range(index+1, len(nums)):
if nums[index] + nums[sub] == m:
if index not in items and sub not in items:
items.append(index)
items.append(sub)

print(items)
```

**解析**

```text
【核心考点】 算法基础 数组遍历 双指针/哈希表
【题目解析】
这是一道经典的“两数之和”问题，考查基本的算法思维和编程实现能力。题目要求找出数组中两个数之和等于目标值的下标，且同一元素不能重复使用。给出的答案使用暴力枚举法（双重循环），虽然能解决问题，但时间复杂度为O(n²)，在面试中通常会追问更优解。
【参考答案要点】
方法一（暴力枚举）：使用两层循环遍历所有组合，检查是否满足条件。时间复杂度O(n²)，空间复杂度O(1)。
方法二（哈希表）：遍历数组，用哈希表存储已访问元素的值和下标。对于当前元素nums[i]，检查target - nums[i]是否在哈希表中，若存在则返回结果。时间复杂度O(n)，空间复杂度O(n)。
【面试角度】
面试官通常期望你从暴力解法开始，然后主动提出优化方案。能分析不同方法的时空复杂度，并考虑数组是否有序（有序时可用双指针法），会展现更全面的思考。另外，注意题目要求返回下标，而不是元素值。
【易错提示】
答案中的代码使用了额外的items列表来避免重复使用元素，但逻辑上存在缺陷：当有多个相同值的元素时，可能漏掉有效组合。更严谨的做法是使用哈希表或双指针法。
```
